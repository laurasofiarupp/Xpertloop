# Xpertloop prototypes

Two independent versions for before-and-after comparison:

- **Original:** `xpertloop/dist/index.html`
- **Expert Loop New:** `xpertloop-new/dist/index.html`

Open either HTML file directly in a browser. No build or package installation is required. For a local server, run `node preview.cjs` from the corresponding project directory. The original uses port 4173 and the new version uses port 4174.

Each prototype saves its demo workspace in a separate browser localStorage key.

## Included experiences

Agent management, test conversations, training resources and Q&A, unanswered-question resolution, analytics, content drafting, and billing screens. The revised version also includes user-defined groups, status filters, pause/resume, monthly reporting, and updated visual design and motion.

## Prototype boundaries

AI responses and content generation are simulated. Resource uploads save metadata only. Billing does not create real charges or subscriptions. No real client records are included. Statistics and sample personas are illustrative.
