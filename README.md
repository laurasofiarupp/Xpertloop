# Xpertloop prototypes

## Open the prototypes

- [Expert Loop New — latest design](https://laurasofiarupp.github.io/Xpertloop/xpertloop-new/dist/)
- [Xpertloop — original design](https://laurasofiarupp.github.io/Xpertloop/xpertloop/dist/)

Both prototypes are hosted with GitHub Pages. Commits pushed to `main` publish automatically after the Pages deployment completes.

## Source

- `xpertloop/`: preserved original prototype
- `xpertloop-new/`: revised prototype for ongoing design work

Open either `dist/index.html` directly in a browser. No build or dependency installation is required. For local preview, run `node preview.cjs` inside its project folder; the original uses port 4173 and the revised version uses 4174.

Each version stores its sample workspace separately in your browser. Changes you make in a local preview do not automatically transfer to the hosted site's browser storage.

## Prototype scope

AI chat and social content drafting use simulated responses. Training uploads store resource metadata. Billing screens do not create real charges. Client activity and statistics are examples.

The revised design includes user-defined groups, status filters, pause/resume, monthly analytics, training Q&A, and animated interactions.
